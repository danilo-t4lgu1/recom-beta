# Plan 11.1: Backend Domain Models & Query Selectors

## Objective
Implementar as funções de domínio puro em `src/api/admin-intelligence.js` para busca rápida de produtos, inspeção determinística de vitrines com pesos/motivos, agregação de saúde do catálogo (11 categorias + disjuntor de segurança) e extração paginada dos 1.373 pares de co-compra reais (`co_purchase_pairs`). Criar suíte de testes unitários com Vitest e atualizar o script de sincronização `prepare-admin-api.mjs`.

<task type="auto">
  <name>Criar módulo de domínio puro src/api/admin-intelligence.js</name>
  <files>src/api/admin-intelligence.js</files>
  <action>
    Implementar funções nomeadas puras (sem I/O, recebendo snapshot de produtos e pares de co-compra já materializados):
    1. `searchCatalogProducts({ snapshotProducts, query, limit = 20 })`: Busca insensível a maiúsculas/minúsculas por nome, ID, cor ou categoria nos produtos publicados e ativos.
    2. `inspectProductRecommendations({ productId, snapshotProducts, maxRecommendations = 8 })`: Executa `recommendForProduct`, mapeia os candidatos com seus motivos de match (`proven_look`, `same_fabric`, `color_stock`), peso (0, 1, 2) e resumo de estoque/variantes.
    3. `getCatalogHealth({ snapshotProducts, writeLogRows, dailyRecomputeLogRows })`: Agrega produtos ativos por grupo/categoria, contagem de produtos com recomendação, percentual de cobertura por categoria, diagnóstico de itens sem recomendação e métricas do disjuntor (churn recente vs teto de 30%, apagão vs teto de 10%).
    4. `getCoPurchasePairsReport({ coPurchasePairs, snapshotProducts, page = 1, limit = 25, category = null, onlyInStock = false, sortBy = 'count' })`: Pagina e enriquece os pares com nomes, fotos/handles, categorias e status de estoque das peças A e B.
    AVOID: Fazer queries SQL diretas ou chamadas de rede dentro deste módulo; manter pureza arquitetural (/backend-architect).
  </action>
  <verify>node --test-only ou syntax check com node -c src/api/admin-intelligence.js</verify>
  <done>src/api/admin-intelligence.js criado e exportando todas as 4 funções com JSDoc completo</done>
</task>
