<objective>
Construir os dois lados da fatia "leitura + renderização" do spike: o endpoint próprio somente-leitura do backend (PLAT-05), que absorve o token OAuth e nunca o expõe, e o Script NubeSDK (FRNT-01) que consulta esse endpoint e prepara a chamada de renderização — sem ainda publicar/verificar visualmente na loja real (isso é o Wave 4).

Output: Endpoint HTTP `GET /recommendations/:productId` funcional localmente; projeto `nube-sdk-script/` com Script buildado (`dist/main.min.js`) pronto para publicação no Wave 4.
</objective>

| Boundary | Description |

| Navegador do visitante ↔ Endpoint próprio | Script roda no navegador (Web Worker), consulta o backend via HTTP público — nenhuma credencial da Nuvemshop cruza essa fronteira |
| Backend ↔ Cliente npm registry | Instalação de pacotes `@tiendanube/*` (marcados [SUS] em RESEARCH.md Package Legitimacy Audit) e `create-nube-app` (não usado, per checkpoint) |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
