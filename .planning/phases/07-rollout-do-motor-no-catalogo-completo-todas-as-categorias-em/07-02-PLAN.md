## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API pública Nuvemshop → ingestão | Dados de produto (nome, tags, `published`) vêm de fonte externa não-confiável (V5). |
| ingestão → SQLite | Toda escrita usa prepared statements com params nomeados (T-02-04). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-04 | Tampering | Migração `ALTER TABLE` corromper/derrubar o `data/catalog.db` real já com runs | mitigate | Padrão idempotente `PRAGMA table_info` + `ALTER TABLE` já validado em produção (product_group_canonical); teste de migração sobre banco pré-existente. |
| T-07-05 | Tampering | SQL injection via nome/tag/categoria de produto | mitigate | Exclusivamente `db.prepare(...).run(params)` com params nomeados; nenhuma concatenação de string (V5, já aplicado). |
| T-07-06 | Tampering / DoS de negócio | Baseline do disjuntor calculado da fonte errada (recommendation_baseline singular) mascarando churn de conjunto | mitigate | `getLastWrittenValuesForAllProducts` lê o array completo de `write_log.written_value`; teste garante que só a última linha success por produto conta. |
| T-07-SC | Tampering | Instalação de pacote (supply chain) | accept | Nenhuma dependência nova (RESEARCH §Package Legitimacy Audit: N/A). |
</threat_model>
